# AtlasV 招聘页（EVP）

面向候选人的 AtlasV 员工价值主张落地页。纯静态：单文件 `index.html` + `assets/`。

## 本地预览

```bash
python3 -m http.server 8899   # 然后打开 http://127.0.0.1:8899
```

## 内容口径（与 atlasv.com 对齐）

- 6 亿+ 全球用户、150+ 国家和地区、10 款在营产品
- 办公地：杭州 / 广州 / 新加坡
- 产品数据（评分 / 下载量 / 官网链接）取自 atlasv.com 与各产品官网
